# 案内サイネージPWA ver. 2.1.0 — 情報端末の試作

駅サイネージ専用の独立した静的PWAです。おはなし絵本とは分離を維持しています。
通常の画像案内を流しながら、左側から必要な情報を選べる試作です。

## 操作

1. HOMEの「駅案内」をタップすると、横画面・全画面を要求して案内を開始します。
2. 左メニューから「案内」「IC」「時刻表」「運賃」「避難」を選びます。
3. 運賃は出発駅を選び、到着駅ボタンをタップすると金額を大きく表示します。「運賃表を表示」で一覧も開けます。
4. 案内以外で60秒操作がなければ通常の案内に戻ります。画面や埋込時刻表内の操作で延長します。戻る10秒前に予告を表示します。
5. 右上の「···」を2秒長押しすると係員メニューが開きます。キーボードではフォーカスしてEnterまたはスペースを2秒長押しします。
6. 係員メニューにHOME、全画面表示／解除、設定、更新、ver.表示を集約しています。HOMEへ戻ると読み上げを停止します。
7. 設定で表示時間5秒／10秒／読み上げ終了までと、案内への復帰30秒／60秒／120秒を選べます。起動中のみ有効です。

全画面・横固定のAPIが使えない端末では通常表示を継続します。縦画面でもメニューを操作できます。右上長押しは操作を隠すための試作で、PIN認証や端末のキオスクロックではありません。
HOMEは係員が起動・外部フォルダ読込に使う既存管理画面です。元の「列車内案内」「避難誘導」はdata:nullのままです。今回の避難デモは「駅案内」に入った後の左メニューから開きます。

## 収録内容と元資料

### 案内・IC
駅案内3枚の画像・文章・順番は変更していません。
1. ic-staff.png：係員とIC処理機。日本語読み上げあり。
2. ic-guide-01.png：IC対応駅の路線図。無音。
3. ic-guide-02.png：乗車パターン別の使い方。無音。

「IC」は既存画像2・3を複数ページで再生します。元のstation.jsonは変更せずsignage/ic.jsonを追加しました。
入口タップ処理内でprimeSpeechFromUserGesture()を呼ぶ位置を維持し、その後、非同期取得より前に全画面を要求します。

### 時刻表
2026timetable-v0.4.5-trial.zip の paper/2027_timetable_scroll.html を content/timetable.html としてそのままコピーしました。元HTML内の表題は2026年3月14日ダイヤ改正です。ファイル名の2027を現行ダイヤの年度とは扱いません。
時刻・駅名は変更していません。駅名固定スクロール型の既存レイアウト試作をiframeで内部表示します。元HTMLは単独で完結しており外部CDN依存はありません。時刻表アプリ本体や別Service Workerは組み込んでいません。

### 運賃
元資料：添付「運賃.xlsx」、シート「智頭線」。14駅、下三角表の91区間を抽出しました。駅名はC3、D4…P16の対角セルを採用しています。「宮本」／「宮本武蔵」の表記差は、対角セルの「宮本武蔵」を使用。「あわくら」「河野原」も元資料の表記のままです。
content/fares.jsonに各金額・駅名の元セルを記録しました。画面上の全区間表は同じ金額を両方向へ展開しています。同一駅は「—」です。
元資料には大人／小児の区分、適用日の記載がありません。「資料記載の運賃」と表示し、小児額の推計や大人区分の断定はしていません。運賃の確定運用前に区分と適用日を確認してください。

### 避難
元資料：添付「避難es0.0.2.html」。黄色背景・点滅、動く矢印、避難経路／足元注意／トンネル出口200m／広場で待機の4画面を5秒ごとに切り替える動作を維持しています。
距離・方向はサンプルのため、外枠に「デモ（距離・方向はサンプル）」を表示します。元HTMLのVoice ON/OFFは音声を発しないダミーボタンだったため、組込みコピーではCSSで非表示にしました。実音声を追加したものではありません。
短い横画面でも全体が収まるよう文字サイズと余白のみ追加CSSで調整しています。他メニューへの移動時はiframeを取り外し、デモのタイマーを終了します。通常メニューへの恒久採用や実際の避難方向を決めたものではありません。

## 既存機能
画像、SpeechSynthesis、自動ページ送り・ループ、無音ページ、前後縮小プレビューとタップ移動、Wake Lock、JSON読込、外部フォルダ読込を維持します。
5秒／10秒は最低表示時間で、読み上げが長い場合は終了まで待ちます。読み上げ終了モードの無音ページは5秒です。音声エンジンから終了・エラー通知が来ない場合に待ち続ける既存の課題は未改修です。
外部フォルダはbook.jsonまたはbook.txtと画像を読みます。画像のみの場合はファイル名順の無音表示です。再起動後は再選択します。同名画像の重複は避けてください。
フリック、一時停止ボタン、ページごとのdurationMsは未実装です。

## オフラインと安全更新
初回はオンラインで開き、係員メニューに「オフライン用の保存が完了しました。」と出ることを確認します。以後は保存済みファイルを優先します。
案内画像、IC JSON、時刻表HTML、運賃JSON、避難HTML、操作用JS/CSS、manifest、アイコンを保存します。埋込HTMLのナビゲーションにもそれぞれのキャッシュを返します。
係員メニューの「更新して再起動」は、公開版の確認→全ファイルの取得完了→切替可能状態の確認→切替→再読込を行います。取得失敗時は旧版を残してエラーを表示します。失敗した新版の未完了キャッシュだけを削除します。
旧版キャッシュ、絵本側のキャッシュ、localStorage、IndexedDBは削除しません。端末に永続保存する利用者編集DATAは本アプリにはありません。外部フォルダ選択と設定は元から起動ごとの扱いです。
version.js の SIGNAGE_VERSION が画面ver.とキャッシュ名の共通値です。現在signage-pwa-v2.1.0。更新公開時には必ず番号を上げ、全ファイルをまとめて配置します。同じ番号を再利用しません。
端末OSが保存領域を消去した場合はオンラインでの再取得が必要です。音声のオフライン動作は端末の日本語音声エンジンにも依存します。

## ファイル構成と今回の変更
変更：index.html、app.js、sw.js、version.js、README.md。
追加：terminal.js、terminal.css、terminal-config.json、fares.js、signage/ic.json、content/timetable.html、content/fares.json、content/emergency.html。
変更なし：元のcatalog.json、station.json、案内画像、アイコン、manifest、従来のstyle.css、update.js。
app.jsは端末画面への接続、情報表示中のWake Lock再取得、重複Wake Lock取得の抑制を追加しました。音声初期化とページ再生の計算は維持しています。

案内の追加は画像→個別JSON→catalog.jsonの順です。画像パスはindex.htmlの階層基準、UTF-8、pages配列順で表示します。speech空文字は無音です。
情報端末の初期復帰時間・長押し時間・各コンテンツ入口はterminal-config.jsonにあります。組み込むファイルは同ファイルのassetsへ登録してキャッシュ対象にしてください。iframeには内容と依存を確認したローカルHTMLだけを使用します。

## 確認結果
PCのEdge 154を使った専用プロファイルで確認：
- 案内表示、入口での音声初期化呼出し、IC前後移動、HOME復帰。
- 時刻表内部表示、運賃駅選択と大きな金額表示、全91区間の両方向の表表示。
- 避難の自動切替、短い横画面（844×390）での表示、ダミー音声ボタン非表示。
- 係員メニュー長押し、無操作復帰、iframe内操作による時間延長、戻った後のiframe破棄。
- ブラウザー完全終了→通信遮断で再起動→時刻表・運賃・避難を含む表示。
- 新版HTML取得を503にした失敗で旧版保持、正常更新・再読込・ver.切替、更新後オフライン時刻表。
- 全91金額と14駅名を元Excelセルへ再照合。
- 元の案内JSON・画像・manifest・update.jsが前版と同一、時刻表HTMLが取り込み元と同一であること。

実機未確認：iPhone／AndroidのHOMEアイコンからの機内モード起動、実音声、横画面固定・全画面、Wake Lock。音声はPC試験で模擬エンジンを用い、実際の聞こえ方を確認したものではありません。タイマーの無操作試験はブラウザー時計を進めて検証しています。
