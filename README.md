# 案内サイネージPWA 2.1.1-trial

2.1.0-trialを基準に、運賃検索・金額表示・運賃表表示と運賃データを削除しました。
左メニューは「案内」「IC」「時刻」の3つです。避難表示のメニュー・設定・キャッシュ登録を外しました。content/emergency.htmlは独立資料として残しています。

## 操作
HOMEで駅案内をタップすると自動再生します。左右の縮小画像で前後移動できます。
ICは内蔵IC案内、時刻は内蔵の時刻表レイアウト試作HTMLを表示します。
無操作で案内に戻ります（初期値60秒、係員設定で30秒・60秒・120秒）。
右上「···」を2秒長押しすると係員メニューが開きます。HOME・表示時間・全画面・更新操作を行えます。
表示時間は5秒・10秒・読み上げ終了まで。読み上げが長い場合は終了まで待ち、読み上げ終了モードの無音ページは5秒です。
対応端末ではWake Lockを使用します。入口タップでの音声初期化処理を維持しています。
フォルダ読込はbook.json・book.txtと画像に対応し、再起動後は再選択が必要です。設定も起動中のみ有効です。

## 公開と更新
このフォルダの中身をGitHub Pagesの公開先に配置してください。初回はHTTPSでオンライン起動し、係員メニューのオフライン保存完了表示を確認します。
係員メニューの「更新して再起動」で新版を取得・切り替えます。必要ファイルを全部取得してから切り替え、取得失敗時は現在の版を維持する既存方式です。旧キャッシュも保持します。
公開時は全ファイルをまとめて交換してください。以降の更新でもversion.jsの番号を上げてください。
旧版の運賃画面が残る端末では係員メニューから更新し、2.1.1-trialを確認してください。複数タブは更新後に開き直してください。

## 構成
app.js：既存の画像再生・音声・Wake Lock
terminal.js / terminal.css：利用者メニュー・係員操作・時刻表連携
terminal-config.json：IC・時刻表パスと無操作時間
catalog.json / signage/*.json / images/：案内セット
content/timetable.html：既存の時刻表レイアウト試作
sw.js / update.js / version.js：オフライン保存・更新
